# Control audit export completeness

`ControlAuditSink.export(path)` writes the existing analyser-readable YAML at `path` and a version 1 sidecar at `path.manifest.yaml`. `exportText()` remains raw YAML with no manifest or added records. Records and counters are captured under the same sink lock; filesystem writes happen afterwards.

The sidecar contains `format: mongoose-control-audit`, `version: 1`, `sha256` of the exact exported UTF-8 bytes, `total`, `retained`, `dropped`, `sinkFailures` and `complete`. `total` counts records added to the ring, including evictions; `total = retained + dropped`. Failed conversions/writes increment `sinkFailures` separately. `complete` is true only when both loss counters are zero. `retained` must equal the number of nonempty YAML documents in the artifact, including fallback records.

Use `ControlAuditExport.verify(path)` when reopening an export on another machine. It reads only the two files and returns `COMPLETE`, `INCOMPLETE` or `UNKNOWN`. Missing, malformed, unsupported, inconsistent or mismatched sidecars are `UNKNOWN`. Incomplete or unknown evidence must not count as an invariant PASS. A complete sidecar only permits validation: a passing investigation also requires no invariant violations, no unverifiable invariants and all required external ledgers. Existing in-memory invariant APIs retain their semantics; their `ok()` alone means no observed violation, not sufficient evidence.

Publication invalidates the previous sidecar before writing either new file. An interrupted export therefore has no valid completeness claim; a hash mismatch also fails closed. Writers must serialize exports to the same path. Copy both files together and validate them before investigation. SHA-256 binds the sidecar to the YAML and detects accidental alteration or mismatched copies; this is not a digital signature and does not authenticate an adversarially rewritten pair. Completeness describes this sink's captured history, not external effects, uninstrumented activity, or omitted exports from other groups.
